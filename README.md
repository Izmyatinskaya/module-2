# Мой первый репозиторий

Учебный проект по освоению Git и GitHub.

## О проекте

Этот репозиторий создан в рамках прохождения модуля 0 —
«Какие бывают системы контроля версий?».

## Что я изучил(а)

- Что такое системы контроля версий (VCS)
- Виды VCS: локальные, централизованные, распределённые
- Основы работы с Git
- Настройка SSH-ключа для GitHub
- Базовые команды: `clone`, `add`, `commit`, `push`

## Полезные команды Git

| Команда | Что делает |
|---|---|
| `git clone <url>` | Клонировать репозиторий |
| `git status` | Показать состояние файлов |
| `git add <файл>` | Добавить файл в индекс |
| `git commit -m "..."` | Зафиксировать изменения |
| `git push origin main` | Отправить изменения на GitHub |
| `git pull` | Забрать изменения с GitHub |
